# 아함·니까야 아카이브

한역 4아함(김윤수 역주)과 빠알리 4부 니까야(초기불전연구원 역)를 한곳에 모아,
경 번호로 검색하고 서로 대응하는 경을 오갈 수 있게 만든 정적 사이트입니다.

## 상호 연결

역주에 적힌 상응 관계를 파싱해 **3,298개 경**을 양방향으로 연결했습니다(연결 쌍 4,004개).

- 본문 속 상응 표기(`SN 22:90`, `잡 [2]10:262`, `증일 4:9:8` 등) 9,465곳이 링크로 바뀌어 바로 이동
- 각 경 위쪽 "상응·참조 경" 상자에서 대응 경 목록 확인
- 한쪽에만 적힌 관계도 역방향으로 자동 생성

예) 초전법륜경(S56:11)에서 잡아함 262·379경과 증일아함 10:19:2경으로,
그 반대 방향으로도 오갈 수 있습니다.

## 검색

경 번호를 그대로 입력하면 됩니다: `잡262` `중88` `증일4:9:8` `S56:11` `M10` `D16` `A4:1`
경 제목(`천다경`, `초전법륜`)으로도 찾을 수 있습니다.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 **전부** 올립니다(폴더 구조 그대로).
3. 저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 지정합니다.
4. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

이미 올린 저장소를 갱신할 때는 `.git` 폴더만 남기고 기존 파일을 지운 뒤
이 폴더의 내용물을 넣고 커밋·푸시하면 됩니다.

## 알아둘 점

- **반복품(peyyāla)** 은 원문이 여러 경을 한 항목으로 묶어 범위로 적은 그대로 수록했습니다
  (예: `태어남 경 등(S12:72~81)`). 범위 안의 개별 번호로 참조가 들어와도 해당 항목으로 연결됩니다.
- 경 번호가 비어 있는 자리는 원본 번역에 그 코드가 없는 경우입니다.
- 상윳따·앙굿따라 단위로만 적힌 참조(`S45`처럼 경 번호가 없는 것) 115건은
  특정 경을 가리키지 않아 링크를 걸지 않았습니다.
- **원본 표기 오류 네 곳을 보정**했습니다.
  - 디가 니까야 D8: `Kassapasīhanāda Sutta(28)` → D7과 D9 사이 위치로 확정
  - 앙굿따라 둘의 모음 6건: `A21:2` → `A2:1:2` (빨리어 줄의 `(AN 2.2)`로 확인)
  - 증일아함 `49:51:7`: 법수 표기 `[11:27]` → `[보유14]` (앞뒤가 `[보13]`·`[보유15]`)
  - 맛지마 제12장 차례대로 품(M111~120): 품 표제가 원본에 없어 보충
