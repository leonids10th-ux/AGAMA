A5:102앙굿따라 니까야

신뢰할 수 없음 경

♦ 102. “pañcahi, bhikkhave, dhammehi samannāgato bhikkhu ussaṅkitaparisaṅkito hoti

pāpabhikkhūti api akuppadhammopi .

♦ katamehi pañcahi?

1. “비구들이여, 다섯 가지 법을 갖춘 비구는 신뢰할 수 없고 의심스럽다.

비록 그가 동요하지 않는 법을 얻었다 하더라도198) 타락한 비구라고 생각한다. 무엇이 다섯인가?”

198) 역자가 저본을 삼은 PTS본에는 api kuppadhammo pi(동요하는 법을 얻었다 하더라도)로 나타난다. 그러나 주석서에는 api akuppadhammo pi라고 나타나고 있으며, 6차결집본의 원문도 이렇게 나타나고 있고 문맥의 흐름으로 봐도 후자가 타당성이 있어 역자는 후자를 따라 옮겼다. '동요하지 않는 법을 얻은 자(akuppa-dhamma)'란 번뇌 다한 자 즉 아라한을 뜻한다고 주석서는 설명한다.(AA.iii.278)

idha, bhikkhave, bhikkhu vesiyāgocaro vā hoti, vidhavāgocaro vā hoti,

thullakumārikāgocaro vā hoti, paṇḍakagocaro vā hoti, bhikkhunīgocaro vā hoti.

♦ “imehi kho, bhikkhave, pañcahi dhammehi samannāgato bhikkhu ussaṅkitaparisaṅkito hoti

pāpabhikkhūti api akuppadhammopī”ti.

2. “비구들이여, 여기 비구가 매춘부에게 자주 들락거리고,199) 과부에게 자주 들락거리고,

다 큰 처녀에게 자주 들락거리고, 중성에게 자주 들락거리고, 비구니에게 자주 들락거린다.

비구들이여, 이러한 다섯 가지 법을 갖춘 비구는 신뢰할 수 없고 의심스럽다.

비록 그가 동요하지 않는 법을 얻었다 하더라도 타락한 비구라고 생각한다.”

199) “그녀의 집을 자주 들락거린다는 뜻이다.”(AA.iii.278)

dutiyaṃ.
